# 발렛 차량 상태 라벨

작성일 2026-10-12 · 주차 파트 (강유나)

발렛 주차를 하는 차 머리 위에 지금 무엇을 하고 있는지 글자로 띄운다. 화면을 보는 사람이 "이 차는 왜 서 있지?"를 바로 알 수 있게 하려는 것이다.

> 컴파일은 통과했다(오류 0개). Unity에서 실행해 화면으로 확인하지는 않았다. 글자 크기와 위치는 실제 화면을 보고 조정이 필요할 수 있다.

## 1. 무엇이 보이는가

| 차의 상태 | 라벨 글자 | 글자 색 | 배경 |
|---|---|---|---|
| 이동 중 (`Moving`) | 이동 중 | 흰색 | 어두운 반투명 |
| 예약을 기다림 (`Waiting`) | 대기 중 | 노랑 | 어두운 반투명 |
| 후진 주차 중 (`Reversing`) | 후진 중 | 하늘색 | 어두운 반투명 |
| 주차 끝 (`Parked`) | 주차 완료 | 초록 | 어두운 반투명 |
| 앞차를 감지해 멈춤 | ⚠ 정지 | 흰색 | 빨강, 0.5초 주기로 살짝 깜빡임 |
| 출발 전 (`Idle`), 만차 (`Full`) | 표시 없음 | — | — |

"⚠ 정지"는 이동 중에 앞차 감지로 멈췄을 때만 나온다. 앞차 감지는 예약 테이블이 꺼져 있을 때만 작동하므로, 예약 ON 쪽 주차장에서는 이 라벨이 거의 보이지 않는 것이 정상이다.

## 2. 바뀐 파일

| 파일 | 내용 |
|---|---|
| `Parking/Visualization/VehicleStatusLabel.cs` (새 파일) | 라벨을 만들고, 상태에 맞춰 글자와 색을 바꾼다 |
| `Parking/Valet/ValetAgent.cs` | `IsBlocked` 읽기 전용 값 추가, `Start()`에서 라벨 붙이기 |

`CarController`는 건드리지 않았다. 뒤로가기·홈, 옵션 토글, 분할 화면 라벨, 시점 버튼도 건드리지 않았다.

## 3. 어떻게 동작하는가

### 라벨은 누가 붙이나

프리팹이나 씬에서 따로 붙일 필요가 없다. `ValetAgent`가 시작할 때 자기 오브젝트에 `VehicleStatusLabel`을 붙이고, 자기 차를 알려 준다. 그래서 주차장 A와 B의 차 여섯 대 모두에 자동으로 붙는다.

비유하면, 택시 기사가 출근하면서 자기 차 지붕에 표시등을 직접 올려놓는 것과 같다.

### 라벨은 어떻게 생겼나

차의 자식으로 `StatusLabel` 오브젝트를 만들고 그 아래 둘을 둔다.

- `Text`: 월드 공간 TextMeshPro 글자
- `Background`: 단색 사각형. 글자보다 2cm 뒤에 있다

위치는 차 바닥에서 2.2m 위, 차 가운데(뒤차축에서 앞으로 1.4m)다. 둥근 모서리는 넣지 않고 네모 사각형으로 대신했다. 배경 크기는 글자 길이에 맞춰 자동으로 정해진다. 레이어는 기본(Default)이다.

### 어느 방향을 보나

**화면을 그리는 카메라마다, 그 카메라를 정면으로 보게 돌린다.** 왼쪽 카메라가 그릴 때는 왼쪽 카메라를, 오른쪽 카메라가 그릴 때는 오른쪽 카메라를 본다. 그래서 어떤 시점에서도 글자가 똑바로 읽힌다.

- 버드뷰: 라벨이 바닥과 나란히 눕고, 글자 위쪽이 화면 위쪽을 향한다
- 운전석·고정 시점: 라벨이 세로로 서서 카메라를 본다

`Camera.main` 하나만 보게 하면 분할 화면의 한쪽에서는 글자가 비뚤어진다. 그래서 URP가 "지금 이 카메라를 그리기 직전"에 알려 주는 신호(`RenderPipelineManager.beginCameraRendering`)를 받아 그때마다 방향을 맞춘다.

비유하면, 사진사 두 명이 번갈아 찍을 때 찍히는 사람이 매번 셔터를 누르는 쪽을 돌아보는 것과 같다.

### 글자는 언제 바뀌나

매 프레임 차의 상태를 읽어서 **직전에 보여 준 상태와 다를 때만** 글자와 색을 다시 넣는다. 같은 상태가 이어지는 동안에는 문자열을 건드리지 않는다. 문자열을 매 프레임 다시 넣으면 TextMeshPro가 글자 모양을 매번 다시 만들어서 느려진다.

정지 경고의 깜빡임은 배경 색의 투명도 숫자만 바꾸는 것이라 글자를 다시 만들지 않는다.

### 한글 글꼴

TextMeshPro 기본 글꼴에는 한글이 없어서 그대로 쓰면 네모로 나온다. 라벨은 UI가 쓰는 `Pretendard-Bold SDF`를 찾아서 쓴다. 찾는 순서는 이렇다.

1. 이미 메모리에 올라와 있는 글꼴 중에서 이름으로 찾는다 (UI가 화면에 있으면 올라와 있다)
2. 에디터에서는 못 찾았을 때 파일 경로로 직접 불러온다
3. 그래도 없으면 기본 글꼴을 쓰고 경고를 한 번 찍는다

경고 기호(⚠)가 글꼴에 없으면 "! 정지"로 대신 보여 준다.

### `IsBlocked`

`ValetAgent` 안에는 "앞차 때문에 멈춘 상태"를 기억하는 값(`_blocked`)이 이미 있었다. 라벨이 읽을 수 있게 밖에서 읽기만 되는 창(`IsBlocked`)을 하나 냈다. 값을 바꾸는 것은 여전히 `ValetAgent`만 한다.

막은 차의 이름은 기존 코드가 멈추는 순간에 한 번만 로그로 찍고 있어서 그대로 두었다.

## 4. 조정할 수 있는 값

실행 중인 차를 선택하면 Inspector의 `Vehicle Status Label`에 보인다. 실행 중에 붙는 컴포넌트라서 여기서 바꾼 값은 저장되지 않는다. 기본값을 바꾸려면 코드의 숫자를 고친다.

| 값 | 기본 | 뜻 |
|---|---|---|
| `Height` | 2.2 | 차 바닥에서 라벨까지 높이 (m) |
| `Forward Offset` | 1.4 | 뒤차축에서 앞으로 얼마나 (m) |
| `Font Size` | 7 | 글자 크기. 10이 약 1m |
| `Padding` | 0.5, 0.25 | 글자 둘레 여백 (m) |
| `Blink Period` | 0.5 | 정지 경고 깜빡임 주기 (초) |

## 5. 하지 않은 것

- **감지 상자 영역 표시**: 선택 사항이라 넣지 않았다. 상자의 폭과 길이가 `ValetAgent` 안에만 있어서, 그리려면 `ValetAgent`에 값을 더 공개해야 한다. 이번 작업은 `ValetAgent` 수정을 `IsBlocked` 추가와 라벨 연결로 제한했다.
- **둥근 모서리**: 스프라이트 없이 단색 사각형으로 대신했다.
- **만차 표시**: `Full` 상태는 요구 문구에 없어서 라벨을 숨긴다.

## 6. 확인할 것

- 버드뷰에서 글자가 읽히는 크기인지. 작으면 `_fontSize`를 키운다.
- 천장 배관이나 조명에 라벨이 가려지지 않는지. 가려지면 `_height`를 낮춘다.
- 배경 사각형이 글자 뒤에 제대로 깔리는지. 배경이 글자를 덮으면 그리는 순서(`sortingOrder`)를 본다.
- 한글이 네모로 나오면 콘솔에 글꼴 경고가 있는지 본다.
